VerdictAI

RAG · Legal document intelligence
The problem Legal documents are dense and full-text search doesn't answer the actual question someone has, it just finds keyword matches with no sense of which clause governs the situation.
What I did Built a RAG pipeline over uploaded contracts, NDAs, leases, and court filings using ChromaDB for clause-aware retrieval and Ollama Cloud for generation, so answers are grounded in the specific document, not general legal knowledge, and every answer cites the clause it came from.
What came of it A working app that takes any PDF or text legal document and answers plain-English questions with citations back to the source clause, with an explicit disclaimer that it's information, not legal advice.

Jobee

Agentic · Job & internship matching
The problem Job searching means checking seven different boards by hand and re-reading listings that don't actually match your profile, most of the time spent filtering, not applying.
What I did Built a pipeline that extracts a candidate profile from an uploaded CV, fires parallel searches across seven job sources, scores every result with embedding similarity against the full profile, and applies a geographic proximity multiplier so local roles rank appropriately against remote ones. Borderline matches get a second AI reranking pass instead of being dropped outright.
What came of it Every search sorts into three tiers, strong matches, worth a look, and everything else, instead of one long undifferentiated list. Nothing is thrown away, just ranked honestly.

NanoCodeGPT

From scratch · Decoder-only transformer
The problem Using an API is easy. Understanding what's actually happening inside a language model, attention, tokenization, sampling, is a different skill, and it's one that's easy to skip if you only ever call someone else's endpoint.
What I did Built a decoder-only GPT-2-style transformer from scratch in PyTorch, no pretrained weights, trained on a dataset of 8,000 Python functions, with exposed controls for temperature, top-k sampling, and max tokens so the model's behavior is visible, not hidden behind a chat interface.
What came of it A small (~10M parameter) model that completes real Python function signatures, and a working understanding of the mechanics that every hosted LLM API abstracts away.
